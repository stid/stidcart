# Bundled fonts

Geist and Geist Mono, the stid design system's faces (D-046), shipped inside the app so it works
offline (D-047). Each is the Latin and Latin Extended subset of the variable font, copied unchanged
from Fontsource 5.3.0 (`@fontsource-variable/geist`, `@fontsource-variable/geist-mono`).
`../styles/fonts.css` declares them.
