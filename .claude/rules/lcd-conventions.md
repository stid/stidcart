Key meanings:

- **artifact-root** — where LCD's durable artifacts live (`MAP.md`, `DECISIONS.md`, and the
  `work/<slug>/` per-work-item folders). Chosen once at onboarding; everything else derives from it.
- **map / decisions / work-item-dir** — resolved paths the suite reads; derived from `artifact-root`.
- **spec / living-spec** — `living-spec: off`, so `SPEC.md` is never created and LCD behaves exactly
  as it would without it. This is a greenfield repo; there is no current state to index yet. Flip to
  `on` and seed `SPEC.md` from the plugin's `templates/living-spec.md` once re-deriving "what does
  stidcart do now" from the work-item chain gets expensive.
- **test-placement** — Cargo discovers tests by convention, so placement is genuinely low-stakes
  here. **This is the opposite of ndefpack**, where a test file missing from the `NDEFPACK_UNIT_TESTS`
  list in `tests/CMakeLists.txt` compiles into nothing and reports a false green. Nothing like that
  trap exists in this project; do not carry the habit over.
- **test-discovery-glob** — integration targets under `crates/*/tests/` become one binary each;
  inline `#[cfg(test)]` modules are compiled into their crate's unit-test binary. Both are collected
  without registration. The glob covers the integration half only, because that is what
  `test-placement` targets — inline unit tests have no path pattern to express.
- **scoped-test / bail / single-test** — `{path}` is a test source path
  (`crates/stidcart-core/tests/directory.rs`); `basename … .rs` strips it to the cargo test-target
  name. `{name}` is a full test path (`encodes_hidden_flag` or `tests::encodes_hidden_flag`).
  **`bail` is identical to `scoped-test` on purpose**: libtest has no in-binary fail-fast, so there
  is nothing to add. Cargo does stop after the first failing *target*, which is the only bail
  granularity available. Diagnose a failing binary by reading its output, not by re-filtering.
- **gate** — format check, clippy at deny-warnings, then the full suite. There is no separate
  typecheck step; `cargo clippy` compiles. Clippy is the static-analysis half that ndefpack lacked
  entirely.
- **eval** — `n/a`. Output is byte-exact cartridge images compared against frozen fixtures.
- **maintenance-bundle** — the gate plus a dependency check. `cargo outdated` is not installed on
  this machine, so `cargo update --dry-run` stands in; swap it if `cargo-outdated` is added.

## Constitution notes

> Must-restate constraints from this project's `CLAUDE.md` + `.claude/rules/*` + `MAP.md`
> invariants that a Deep-lane `plan.md` Constitution check and the red-green loop should honor.
> Repeated here so they survive on a fresh clone without the maintainer's machine.

- **Byte parity against the frozen fixtures is the primary correctness signal for the write path.**
  A change that alters produced bytes must update the fixtures deliberately and say why in the
  commit. Silent fixture churn defeats the whole oracle.
- **The oracle decays — spend it early.** Parity only applies where stidcart is trying to reproduce
  `ndeft`'s output. Features ndefpack does not have have nothing to compare against, so they need
  their own evidence (a boot in VICE, a hardware test).
- **Licence boundary is load-bearing.** `firmware/` is zlib (skoe / ALeX Kazik); everything else is
  GPL-2.0-or-later because the core was written from ndefpack's GPL C. Never move code across it.
- **The core stays a library with no global mutable state and no I/O policy.** That is what keeps
  the GUI toolkit decision reversible, and it is the specific thing that made ndefpack's core
  impossible to reuse. Resist the first `static mut`.
- **Tests first** (the user's global TDD rule). Cargo collects them automatically, so there is no
  excuse to write them after.
- **The crate version lands inside every cart.** The CRT header default name is the tool name and
  version, so bumping it in `Cargo.toml` changes the bytes of every newly built cart and every
  parity fixture built without an explicit `-e`.
- **Format facts come from the spec, not from re-reading ndefpack ad hoc.** The extracted binary
  format lives in the Obsidian vault at `reference/easyflash-cart-format.md`; it records which
  ndefpack behaviours are format-mandated and which are implementation artifacts. Re-deriving from
  the C invites inheriting a quirk by accident.
- **Never commit to `main`; conventional commits** (`feat:`, `fix:`, `refactor:`, `chore:`,
  `test:`, `docs:`) on `feat/`/`fix:`/`refactor/`/`chore/` branches.
- **No feature downgrade without approval** (`~/.claude/rules/no-downgrade.md`); restate +
  list-unchanged before editing (`~/.claude/rules/refinement-protocol.md`).
